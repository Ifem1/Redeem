# Testing

The suite currently contains 47 pytest tests. 11 tests use `direct_deploy` and execute Redeem through the Direct Mode runtime; the remaining tests are static, helper, or protocol-rule checks. The real Direct tests cover deployment, funding, validation, authorization, bounded reads, rule reads, constants, accounting, expiry, and terminal protection. Review-to-settlement and challenge resolution still require a supported Direct VM sender/context fixture before they can be claimed as execution proof. Frontend Vitest covers protocol payload, GEN-unit, bond, lifecycle, and guard helpers. CI uses pinned genlayer-test 0.29.2, genvm-linter 0.11.0, and pytest 9.1.1, followed by web lint, typecheck, Vitest, and build.

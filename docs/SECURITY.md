# Security

Threats include malicious guarantee prose, prompt injection in source pages, source drift/outage, wrong callers, replay/double settlement, challenge griefing, and compromised frontend/indexer code. Contract state—not UI, API, or a human—controls authorization and settlement. Sources are HTTPS and bounded; payouts are read from frozen rules; terminal settlement must zero accounting before transfers.

Residual risk: public web evidence can be unavailable or misleading, and consensus does not make a source truthful. Archived bytes or fingerprints are provenance aids, not proof that every validator saw identical content.

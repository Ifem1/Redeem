# Deployment

Deployment is intentionally not claimed by this repository. Before release, run the linter/schema/typecheck gates, deploy to Studionet, record the address and schema digest, verify deployed source, then run the live scripts and update README with dated evidence.
Deployment remains unclaimed until a fresh Studionet 61999 deployment succeeds. Use the scripts in scripts/ with a funded issuer key supplied through the environment; never commit keys. Record the final commit, address, transaction, runner hash, schema digest, and UTC timestamp after confirmation.
